# 0.1.3 发布评估

本包定位为实验版购物流程 Skill 与离线账本工具。它不是生产就绪的自动购物平台，也没有内置电商账号连接器。

## 已验证

- 在维护者的macOS环境运行Python编译检查、29项离线回归测试及匿名样例校验。
- 生成私密与公开HTML/手机文本，检查报价规格和数量、逐包商品映射、公开字段白名单和图片路径保护。
- 在受管浏览器打开匿名公开报告，缩略图加载、点击放大与关闭实际可用。
- 检查包内文件、许可证和文档引用，公开包不包含本人的真实订单、账号登录资料、地址、私密聊天或模型调用凭证。

这些检查验证的是当前样例、反例和本地行为，不能证明真实平台事实、优惠资格或所有输入正确。

## 已披露的限制

- 其他独立用户的本人账号读取、结算、授权售后及到账全流程尚未完成验收。
- 已验证海外真实执行国家站点为零；其他宿主、Windows完整测试尚未实测。
- 同一账本不支持共享并发；parcels表示本批本轮实际退回包裹，不是同一实物多轮往返流水。
- 不会自动找到全网最优凑单，不接入任何固定返利账号，不保证固定省钱金额。
- 离线工具不核验银行流水和平台回执真实性，不计算已实现净节省；金额闭环仍需Agent依据真实证据核对。
- HTML和手机文件依次写出，第二个输出失败时可能已有第一个文件；遇到错误先核已有文件，不当作整次报告成功。
