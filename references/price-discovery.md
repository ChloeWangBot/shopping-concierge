# 优惠路径与核价覆盖

用于真实账号比价、凑单和复盘漏价；不是全网最优求解器，也不保证领取到任何权益。优惠是否存在、可领、可叠加，以本轮账号和精确SKU页面为准。

## 从候选价走到可买价

先固定货号、颜色、尺码、数量、配送地区和允许店铺类型。记录单买结算基线，再检查实际相关的路径；已确认不适用的路径不反复查。每条标为已核实 / 不适用 / 未核实，附金额、限制、时间、来源和缺口。

“只比价”允许查看权益，不包含加入免费会员、注册新账号、授权手机号或开通付费会员；已有明确入会授权时在原范围内执行，不重复询问。未领取权益可给条件试算，不能说该券已经可用。

| 路径 | 应核对什么 |
| --- | --- |
| 店铺免费会员 | 入会礼、会员券、会员首单、关注礼；当前是否已是会员，旧会员能否领取。需要注册、授权手机号等动作时，准备入口并按实际授权执行，不能把有券等同已领可用。 |
| 平台会员与新客 | 现有会员专享、新客资格、首购渠道、App专享；不假设老账号可用，不创建新账号规避资格。付费开通/续费须单独授权，把完整新增费用计入本方案。 |
| 店铺与平台优惠 | 商品券、店铺券、跨店满减、消费券、大促补贴；核门槛计算基数、适用品、互斥、有效期和可用次数。未达到门槛的券不能直接扣除。 |
| 凑单 | 用用户本来就需要且愿意保留的物品试组，核整组结算总额、额外支出和分摊。已有待付款商品可作候选，不能当作用户必需品。无需购买的额外品不能隐去成本。 |
| 支付优惠 | 收银台银行卡/钱包优惠、付款渠道、限额和名额；区分订单应付与收银台应付，不代用户选择分期或开通金融产品。本人验证前不能称已付款。 |
| 返利 | 对精确商品链接查可返金额、账号返利比例、跟单渠道、券/红包/购物金兼容和结算条件。平台身份/入口不明则待核，不套用另一店铺或另一商品的佣金。 |
| 特殊购买方式 | 预售定金/尾款、直播专链、购物金等，仅在有相关线索时核对。定金不是总价；购物金需计完整新增充值成本，尾款未知不称最终可买价。 |

用户说“我买得更便宜”时，先读新订单详情和付款回执，核同款与分摊优惠，再回溯差价来源；不能直接认定是会员券、返利或付款立减。新订单事实应更新报告，但不能冒充可随时复现的单买报价。

## 凑单收益与返利口径

- 单买、整组凑单、每件分摊、已付款成交分栏。整组买入成本和额外物品必须一起展示，不能将一件的分摊价当作独立可买价。
- 保留集合相同时比较整组成本；集合不同时并列说明，不直接宣称更划算。例如目标单买394元，凑单组应付425元、目标分摊367.16元：若额外物品不需要，实际多付31元，不能称省26.84元。
- 默认不以买后退掉凑单品作为优惠前提。用户已有部分退款时，回读实际退款、券返还/追回及剩余订单金额，再核最终成本；不从退款按钮推断券一定保留。
- 预估佣金、买家预计可提现返利和已到账现金分开。仅拿到预估佣金不减入已确认付款；输出“支付X，预计可返Y（条件），预计返后Z”，未知返利留待核，不能默认0后声称已完成返利核查。
- 账号级一次性券不可在多个方案合并使用。新用户/会员权益也不能跨账号复用；每个用户自行核价，不继承维护者的资格和金额。

## 输出与停止条件

只有精确规格、配送、数量、费用及账号优惠已在当前确认订单页核实，才能参与“已核实可结算方案”的最低排序；仅商品页的394元仍是展示价，不能进入该排序。未到尾款阶段的预售总额标预计，返利尚未到账标预计，已付款成交另列。

凑单退款后先算整组最终支出＝整组已付＋追加扣款/券追回＋费用−实际已到账退款；无法确定整组或退款终态就保留待核。只有额外物品全部退完且费用/优惠已确定时，才能把剩余组支出归到唯一保留商品；多件保留时另核实际分摊，不能直接沿用退款前分摊。推广者佣金不等于买家返利。旧订单若已付，须纳入重复资金占用与退单成本；仅待付款则不算已支出。

面向用户先给最适合当前需求的方案，再给单买备选；每条包含平台/店铺、精确规格、整组包含物品、付款额、分摊额（若有）、预计返利（若有）、新增会员/充值/运费、核验阶段和时间。高佣金不能盖过更低的无返利总成本，邀请推广关系也不能影响排序。

结束本轮需覆盖目标平台与实际相关路径，或明确哪些路径因资格、登录、缺入口或平台限制未核实。搜索结果、商品页、结算、付款分别是不同证据；不得只查到结算便宣称全网最低。提交前刷新本批订单和当前结算，发现重复或金额/规格改变时重新核对；结果未知先查账，不重复点击。

本节是Agent执行与报告要求。离线账本工具不自动找券、判断资格或求最优组合；现有字段不能表达的覆盖/会员/返利条件存于同批证据和报告，不伪称工具已校验这些平台事实。

## 去身份化的真实漏价复盘

一次同店同款同尺码比价中：商品493元，官方立减74元，单买使用25元红包后结算394元。用户实际成交详情显示，消费券分摊51.84元，实付367.16元，差26.84元。

能证明：旧方案漏查了更优消费券路径；新成交的金额和优惠来源已核。不能证明：367.16元现在单买可复现、消费券必然来自入会、一定存在返利，或凑单后部分退货不会改变成本。此案例仅用于学习核价过程，不作为新用户可领取权益或当前价格。
